🚀 QUICK 3-STEP SETUP (Takes 2 Minutes)

STEP 1: Get Free API Key
────────────────────────
  1. Go to: https://console.groq.com/keys
  2. Click "Sign Up" or "Sign In"
  3. Complete email verification
  4. Copy your API key (looks like: gsk_abc123...)

STEP 2: Add to Your Project
────────────────────────
  1. Open: .env.local (in project root)

  3. Save the file

STEP 3: Start Dev Server

📋 DETAILED SETUP

PART A: Get Your Free API Key
──────────────────────────────

1. Open your browser
2. Go to: https://console.groq.com/keys
3. You'll see the Groq Console login page

4. If you don't have an account:
   a. Click "Sign Up"
   b. Enter your email
   c. Create a password (easy one is fine)
   d. Check your email for verification link
   e. Click the verification link
   f. Done! You're logged in

5. You'll see your API key on the page
6. Copy it (it looks like: gsk_... or gr_...)

PART B: Add Key to Project
───────────────────────────

1. In your project, find: .env.local (in the root folder)
2. Open it with any text editor
3. You'll see: GROQ_API_KEY=
4. Add your key after the equals sign:

   GROQ_API_KEY=gsk_abc123def456...

5. Save the file
6. Important: Don't commit this to git!

PART C: Restart and Test
─────────────────────────

1. Stop the dev server (Ctrl+C)
2. Run: npm run dev
3. Wait for it to say "ready - started server"
4. Open: http://localhost:3000
5. Click on "Grok 4.1 Reasoning" dropdown
6. Type: "Hello, test Groq"
7. Should respond with real AI! ✨

❓ TROUBLESHOOTING

❌ "API Key not found"
   └─ Check .env.local has GROQ_API_KEY=your_key
   └─ Make sure you restarted npm run dev
   └─ Check for extra spaces around the =

❌ "Invalid API Key"
   └─ Verify you copied the full key (it's long)
   └─ Check for accidental extra characters
   └─ Get a new key from https://console.groq.com/keys

❌ "Rate limit exceeded"
   └─ You sent 30+ requests in 1 minute
   └─ Wait a minute and try again
   └─ This is normal - limit resets every minute

❌ "Connection error"
   └─ Check your internet connection
   └─ Make sure Groq API is up (status.groq.com)
   └─ Try again in a few seconds

❌ "Model not found"
   └─ Make sure "Grok 4.1 Reasoning" is selected
   └─ This project is configured for that model
   └─ Restart dev server if dropdown is empty
